# Projects

Superseded · 8 October 2026. Satchel's projects are now topics. Read [topics.md](topics.md) for the current model.

A topic is a subject that memories hang off. A topic with a repository link or tasks is what this page used to call a project. What was still true here, like a topic not being a repository and the UUID being its identity, now lives in topics.md under "What carries over from the project model".

Topics are still stored in the `projects` table, so the database keeps the word project (D34 in [decisions.md](decisions.md)). The earlier version of this page is in the Git history.

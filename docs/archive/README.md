# Historical material

These files preserve the earlier JEFF/Satchel discussion. **They are not the current product specification.** Start with [the current product document](../product.md) and [decision ledger](../decisions.md).

- `jeff-rethinking/`: original Codex reports and visual-direction notes.
- `jeff-handoff/`: the Claude handoff README, decision snapshot, report copies, alternative HTML porting map, and early mockup screenshots.
- `conversation-attachments/`: the two comparison/revision texts supplied by the user.

Files are retained without rewriting their text, including obsolete recommendations, historical local links, dates, and implementation claims. This protects the reasoning trail. Current docs supersede persona/curator proposals, built-in Notion task integration, universal installer assumptions, and unverified prototype mechanisms.

The latest hosted direction leaves the memory/project storage mechanism unresolved; neither the old hosted-provider pilot nor the handoff's all-GitHub design is automatically final. Visual source files are under [design/prototype](../../design/prototype/); rejected early Codex mockups are under [design/archive](../../design/archive/early-codex-mockups/).

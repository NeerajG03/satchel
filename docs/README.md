## How to interpret the documents

- **Agreed direction** records explicit user decisions and constraints from the conversation.
- **Proposed mechanism** describes a coherent way to implement that direction. It is not a claim that the user selected every detail or that the mechanism is proven.
- **Open** identifies a choice or compatibility question that remains unresolved.
- **Historical** material preserves the earlier reasoning, including proposals later rejected.

The latest explicit user decision takes precedence over any document. Within this collection, use the current documents above and the decision ledger to interpret conflicts. The [archive](archive/README.md) and [visual prototype](../design/prototype/Main.dc.html) are evidence, not overriding specifications. A design control changing sample state is not proof of an integration.

This collection preserves available reports and attachments alongside a synthesis of the discussion. It is not a verbatim transcript of every previous assistant response. Original imported files are listed with checksums in [source-manifest.json](source-manifest.json).

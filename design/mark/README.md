# Mark

18 September 2026. The logo is the app's own shell shrunk down: dark frame, paper inset, one orange light, and a Caveat "s" on the paper. The wordmark is "satchel" in Caveat 600 on hardware. See the Mark board on the canvas for construction and rules.

| File | Use |
|---|---|
| `mark.svg` | Full mark with the s. 32 px and up. |
| `mark-small.svg` | No glyph. Favicon at 16 and 24 px. |
| `lockup.svg` | Mark plus wordmark on a hardware bar. Loads Caveat from Google Fonts. |

Grid is 180. Frame radius 22, paper inset 14 with radius 14, header 22 tall, LED radius 6 at (150, 30). Scale the grid, never redraw.
